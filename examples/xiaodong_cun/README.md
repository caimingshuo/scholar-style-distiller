# 实战示例：存晓东（Xiaodong Cun）风格档案

用本 skill 全流程蒸馏的完整真实产物（2026-09-30），展示从语料到可交付档案的每一步长什么样。

## 产出概览

- **语料**：20 篇一作/通讯/主导论文（2019–2026，覆盖澳门大学一作期 → 华为/腾讯效率期 → 腾讯生成期 → 大湾区 GVC Lab 建 lab 期），方法 12 / Benchmark 4 / 系统 2 / 架构 2
- **逐篇证据卡 ×20**（[analysis/](analysis/)）：每条结论锚定到 `tex 文件:行号 + 原文引用`，插图结论均实际打开渲染图观察
- **风格档案**（[profile.md](profile.md)）：视觉与表格指纹 / 写作修辞指纹 / 选题品味 / Idea 设计模式 五节，含 Idea 谱系图与打分卡
- **应用手册**（[style_handbook.md](style_handbook.md)）：由档案衍生的「画图 + 写作 + Idea」操作手册——调色板 hex 全表、Teaser 五型选型、Abstract 四骨架、签名短语库、LaTeX 表格模板、交稿检查单，可直接套用到自己论文
- **盲测验证**：留样论文（SadTalker, 2211.12194）不参与蒸馏，用档案仿写同主题 Abstract 并排比对——结构层命中，两处差距回修档案后通过；记录见 profile.md §五

## 使用边界

本示例是对公开论文的风格分析，仅用于学习写作与思维方式：禁止搬运原文内容进新论文、禁止冒充作者本人或暗示其参与。语料版权归原作者所有。
