## 2 写作修辞

**Abstract 逐句骨架**（src/tex/abstract.tex）：
1. 任务定义句：「Image harmonization aims to modify the color of the composited region with respect to the specific background.」
2. 范式批评：「Previous works model this task as a pixel-wise image-to-image translation using UNet family structures. However, the model size and computational cost limit the ability of their models on edge devices and higher-resolution images.」
3. 报名+首发：「we propose a novel spatial-separated curve rendering network~(S$^2$CRNet) for efficient and high-resolution image harmonization **for the first time**.」
4. 「firstly... Then... Finally...」三步流程句（提取空间分离嵌入 → CRM 生成曲线参数 → 直接渲染原图）。
5. 扩展句：「Besides, we also make two extensions of the proposed framework via the Cascaded-CRM and Semantic-CRM for cascaded refinement and semantic guidance, respectively.」——把扩展当卖点写进 abstract。
6. 量化三连：「reduces more than 90% parameters... still achieves the state-of-the-art performance on both synthesized iHarmony4 and real-world DIH test set... 2048×2048 in 0.1 second」。
7. 代码链接。

**Introduction 段落功能序列**（src/tex/introduction.tex，5 段）：
1. 组合背景→调和任务定义（含「has a broad impact on image editing, relighting and augmented reality」——relighting 在此就埋下其后续伏笔）。
2. 现有 CNN 方法综述 + 效率批评（「their model sizes are too large for the edge devices, such as mobile phone」）。
3. **顿悟段（本文灵魂）**：「Differently, in this paper, we rethink the image harmonization in a totally different way: Reviewing the image harmonization process in image editing software (e.g. PhotoShop), experts tend to adjust the global properties (color curve, illuminant, etc.) over the whole images rather than the pixel-wise color adjustment.」——**从人类专家工作流找原型**，把调和从「逐像素翻译」重构为「拟合全局曲线」。
4. 方案段：CRM 细节（共享 SqueezeNet/VGG16 特征提取 + 单层线性投影 + 曲线渲染）。
5. 扩展段（semantic-CRM / cascaded-CRM「also inspired by the photo editing software since the image editing process generally contains multiple steps」——第二个灵感仍来自软件工作流）+ 量化预告（「only 2% (25% using VGG16 backbone) of the parameters」）。
6. 贡献 3 条（introduction.tex:103-107）：第 1 条即带粗体首发声明「We propose a novel spatial-separated curve rendering network (S$^2$CRNet). **The first** network for both efficient and high-resolution image harmonization.」；第 2 条扩展能力；第 3 条结果。

**Related Work 组织法**（src/tex/related_works.tex）：`\noindent\textbf{}` 分派系：`Image Harmonization`（传统手工特征 → 深度方法按「语义线索/空间分离/GAN 域判别」分述）等；结尾统一判词「However, all the previous deep networks still model this task as a pixel-wise image to image translation problem using an encoder-decoder structure, which suffers from computational inefficiency...」——把整个领域归入一个被挑战的范式，为自己「totally different way」腾位置。

**标志性短语（≥2 例）**：

## 3 选题品味

- **创新类型：Tier 2 表征简化——用「全局曲线参数」替换「逐像素翻译」这一整个范式。** 参数量砍 90%+（SqueezeNet 骨干下仅前人 2%），靠的是问题表征换轨而非网络堆叠；效率与高分辨率能力是表征换轨的免费赠品（曲线渲染与分辨率无关）。
- **问题从哪来：人类专家工作流观察（现象驱动）。** Photoshop 里专家调全局曲线不逐像素改色（intro 顿悟段）——「软件里已有的操作」成为网络结构设计图；cascaded 扩展同理（「the image editing process generally contains multiple steps」）。这与 CoordFill 的 NeRF 迁移不同：灵感源从「别的技术社区」换成「创作工具的人机惯例」，直接预演了 LightCtrl「IC-Light 的渐变掩码用法」「procedural synthesis light map」的创作工具取材路线。
- **实验与消融哲学**：合成（iHarmony4/HCOCO）+ 真实（DIH99）双基准；用户研究；log 轴 time/cost/性能三联图；消融表字母行 + 勾选矩阵，连 loss 类型（L1 vs rL1）都进消融；分辨率影响图专门做一组并顺手记录对手 OOM。
- **与他论文的关系线索（谱系源头）**：(1) 本文确立「调和/光照编辑」主线——intro 即声明 harmonization「has a broad impact on image editing, **relighting** and augmented reality」，Relightful Harmonization（2024）与本篇共享「调和→重光」的概念演化（把颜色曲线换成光照传输）；(2) 「全局编辑参数 + 分辨率无关渲染」→ 其后视频重光里「light map 条件 + 任意底座」的同构思路；(3) 澳门大学 Pun/Cun 联合培养集群在 CoordFill（2022-03）与本文（2021-09）背靠背产出，两篇共享「efficient + high-resolution + for the first time」的效率叙事配方；(4) 被批判的「UNet 逐像素翻译」范式标签，与其 2022 年后全面转向 diffusion 的技术换代形成对照——但「给编辑操作找参数化原型」的思维方式从未改变。

## 4 Idea 设计

- **Idea 原型：现象驱动（主，专家工作流观察）+ 简化驱动（次，砍掉整个像素级解码器）。** 内核：调和不是学「图到图」，而是学「编辑操作的参数」——拟合 Photoshop 式分段曲线 ψ(x, P)，网络只负责从缩略图预测曲线参数 P（前景/背景空间分离嵌入 + 单层线性层），渲染在原分辨率上零成本完成。前/背景分离建模（spatial-separated embeddings）承接 S²AM 的分离思想但把「注意力」换成「曲线参数」。
- **问题表述句式**：「we rethink the image harmonization in a totally different way: Reviewing... experts tend to adjust the global properties... rather than the pixel-wise color adjustment.」——「rethink X in a totally different way + 人类工作流证据」的范式挑战句式；无设问（不同于 CoordFill），是观察-断言式。
- **本文局限可能催生的后续**：(1) 曲线只能表达全局色调，无法处理局部光照/阴影 → 局部光照编辑（relighting）缺口；(2) 分段曲线是手工设计的参数族 → 换成生成模型隐式参数（其 diffusion 转型）；(3) foreground/background 分离嵌入 → 前景感知光照编辑（Relightful Harmonization 的 foreground 传输矩阵）；(4) 「编辑即参数预测」→ 2026 年 CutClaw 把「剪辑」也参数化为 agent 输出（时间戳三元组 c_i=(t_in, t_out)），同一思想在 agent 时代的回声。
