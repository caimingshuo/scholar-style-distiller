## 3 选题品味

- **创新类型：迁移驱动 + 简化驱动（Tier 2）**。把 2403.04258 的 TTT 配方从视频分割迁到图像取证，核心适配矛盾是"测试时没有深度这类免费辅助任务可用"→改用分类头 + 掩码分组构造自监督；效率一侧做减法：用 dropout 把一张图复制成一批 query（TTT-OBQG，`submit/intro.tex:97` "By randomly dropping part of tokens within a given image iteratively, we manage to construct a batch of different samples. This strategy not only improves the performance but also the efficiency"），实现 4.8× 加速（:110）。
- **问题从哪来：对抗性数据竞赛这一根本矛盾**。"generative AI 使伪造进化快于数据收集"（:36）——比 2403 的"数据贵"更进一步：数据永远追不上，所以唯一出路是测试时自适应。零样本设定直接对标"训练集与测试域重叠"的不公平比较并用 † 脚注揭穿（`submit/table.tex:15`）。
- **实验与消融哲学：原子化拆解 + 真实失真鲁棒性**。消融逐项单开关：自监督分类算法（`submit/exp.tex:102`）、不同 query 构造（:121）、patch size（:139）、dropout 比例（:155）、TTT 策略（:173）、逐数据集 TTT epoch 曲线（:241 "The performance is getting better as TTT goes on. Different datasets have different optimal epochs"）+ 定性逐 epoch 演化图（:251）、换 backbone（:331 "Ablation study of QCTTT using different backbones"）。鲁棒性表把 Facebook/Whatsapp/Weibo/Wechat 真实传输链路当失真算掉分（`submit/exp.tex:296-330`）——务实、对抗性思维，且敢报自家弱项。
- **与他论文的关系线索（本批最硬的谱系证据）**：`main.bbl` 自引网：cun2018image "Image splicing localization via semi-global network and fully connected conditional random fields"（ECCV-W 2018，Cun & Pun，`main.bbl:134`）——他博士期就是做图像篡改定位的，本篇是带 TTT 配方回归；首句引用 cun2020improving（TIP 2020 空间分离注意力，`main.bbl:25`）；引自家 FateZero（:87）与 cun2020improving 支撑"图像编辑技术进步"论点；同门链条 liu2023explicit/liu2024dh（Explicit Visual Prompting、DH-GAN，均 Weihuang Liu + Cun + Pun，`main.bbl:144,150,161`）与本篇同第一作者 Weihuang Liu，2403 的 DATTT 亦被引（`main.bbl:254`）。

## 4 Idea 设计

- **Idea 原型：迁移驱动（主）+ 基准驱动（次）**。一句话内核：定位难但分类易（"deep neural networks… can effortlessly determine whether the images have undergone manipulation"，`submit/intro.tex:55`），于是把"易的全局分类"做成"难的局部定位"的测试时自监督引擎：用预测掩码把 token 分成 manipulated/authentic 两组构造 query，让分类头在测试时自我训练 encoder。次原型：以新设定（zero-shot + 五基准 + 真实传输失真）定义战场。草稿注释里保留更早的 insight 表述："image manipulation classification is a global response to image manipulation localization, thereby they are closely related"（`submit/intro.tex:58` 注释行）。
- **问题表述句式**：陈述式动机句——"Our key motivation arises from the consistency between the coarse task… and the fine-grained task…"（:54）；注释稿中还出现过设问式 "How can we cope with the evolving forgery images in the real world?"（:34 注释行），定稿倾向收敛为陈述句。收敛链：伪造技术进化快于数据集 → 需要逐样本自适应 → TTT 需要与主任务强相关的自监督任务 → 分类（易）与定位（难）本是一体两面 → 用预测掩码自举分类 query。
- **局限催生的后续**：逐图 TTT 的推理开销（本文用 dropout 缓解到 4.8×）仍未消除，指向高效/单步 TTT；"分类头只在测试时当引擎用"暗示可换成其他免费辅助任务（深度→分类→下一个免费自监督信号的迁移链仍开放）；"不同数据集最优 TTT epoch 不同"（`submit/exp.tex:241`）指向自适应停止准则。这些插槽结构（辅助任务可替换、更新策略可替换）正是他 TTT 系列可持续出续作的设计方式。
