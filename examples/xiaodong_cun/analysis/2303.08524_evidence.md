## 2 写作修辞

**Abstract 逐句骨架**（corpus report §3）：
1. 任务一句话定义：「Image inpainting aims to fill the missing hole of the input.」——开篇最短句。
2. 双因枚举式痛点：「It is hard to solve this task efficiently when facing high-resolution images due to two reasons: (1) Large reception field... (2) The general encoder and decoder network synthesizes many background pixels synchronously...」——abstract 里就上编号列表。
3. 首发声明：「we try to break the above limitations **for the first time** thanks to the recent development of continuous implicit representation.」——把「第一次」挂在借来的技术（连续隐式表示）上。
4. 「In detail, we down-sample and encode... Then, we take these parameters as the weights and biases of a series of MLP...」——两网络两句话。
5. 收益三连：「Thanks to the proposed structure, we only encode... in a relatively low resolution... Then, the continuous position encoding will be helpful... Also, our framework enables us to query the coordinates of missing pixels only」——「Thanks to...」受益句式。
6. 硬件级量化收尾：「achieves real-time performance on the 2048×2048 images using a single GTX 2080 Ti GPU and can handle 4096×4096 images」——显卡型号入 abstract。
7. 代码链接。

**Introduction 段落功能序列**（submit/intro.tex，5 段）：
1. 需求背景：「With the rapid development of digital media, the demand for image editing... also increases a lot.」
2. 现有方法综述（CNN 系 + hint 引导系各一段带引用）。
3. **设问立论**：「We raise a question: \textit{What makes the inpainting hard in efficiently handling the high-resolution images?} and we attempt to answer this question from the following perspectives: (i)... (ii)...」——先抛问题再自答，两因各成一段（大感受野代价 / 解码器合成多余像素）。
4. 方案段：「We try to break the above limitations via the implicit representation from neural rendering community」——点名移植来源（NeRF/SIREN 社区）+ 「using implicit representation for the first time」；meta-learning 空间自适应参数（cite asapnet）。
5. 效率双解释：「our method can run faster... from two aspects. On the one hand... On the other hand...」——与痛点两因严格镜像。
6. 贡献 3 条（intro.tex 末）：框架条（We propose CoordFill, a novel framework...）+ 组件条（We design an attentional FFC-based block...）+ 结果条（runs faster... and achieves state-of-the-art performance）。

**Related Work 组织法**（submit/related.tex）：三个 `\subsubsection`：`Image Inpainting` / `Continuous Image Representation` / `Efficient Network Structure`——本文两个借来的技术源（隐式表示、高效结构）各占一节，RW 直接为方法的两个成分铺史料。

**标志性短语（≥2 例）**：
- 「for the first time」——abstract「break the above limitations for the first time」+ intro「using implicit representation for the first time」（两处重复）。
- 「Thanks to the proposed structure/decoder, ...」——abstract 与 teaser caption 各出现一次，受益归因句式。
- 「queries the coordinates (x,y) in the missing mask M ... only」——「query ... only」的效率表述贯穿 abstract/intro/teaser caption。
- 「synthesizes many background pixels synchronously」「unnecessary pixels」——把浪费拟成「多余合成」。

**贡献清单范式**：3 条 bullet（框架/组件/结果），第 3 条融合「faster + SOTA」双卖点。

**标题与方法命名**：`\title{CoordFill: Efficient High-Resolution Image Inpainting via \\ Parameterized Coordinate Querying}`（aaai23.tex:173，注释版 106 行措辞一致）——「缩写名: 任务 + via 机制」冒号结构；CoordFill = Coordinate+Fill 直白缩合；组件命名功能式（Parameter Generation Network / Pixel-wise Querying Network / attentional FFC Block→AttFFC）。

## 3 选题品味

- **创新类型：Tier 2 迁移式简化——把神经渲染社区的隐式表示搬进修复任务，同时解决效率与分辨率泛化。** 明确自述来源：「the implicit representation from neural rendering community~\cite{siren,nerf,asapnet}」（intro.tex）；再叠 meta-learning 式条件参数生成（cite asapnet 的 spatial-adaptive 方案）。创新动作 = 「换输出参数化方式」（整图矩阵 → 逐坐标查询），收益（只算洞内像素、坐标重采样任意分辨率）随参数化方式自动出现。
- **问题从哪来：硬件/部署痛点。** 「casual images are in high resolution and on the mobile platform」（intro.tex 第 2 段）；「real-time ... using a single GTX 2080 Ti GPU」（abstract）——单卡实时、对手 OOM 是其立论的弹药库。**资源节约叙事**是本文与 LightCtrl（training-free）/CutClaw（现成 MLLM 编排）一脉相承的底色。
- **实验与消融哲学**：
  - 分辨率规模化主表（512→4096），对手逐级 OOM 退出；SPEED 列与质量列同权。
  - 独立效率小节（`Efficiency Analysis`，exp.tex:35）+ 速度-分辨率曲线图（三种 mask ratio）； supervision 策略消融与解码器选择消融均配定性图（images/ablation.tex:26/58「Qualitative comparisons of decoding using a shared MLP, CNN, and the pixel-wise querying network」）——消融不只报数字，还给看图。
  - 独立 Limitation 小节 + 失败例图（复杂背景 dazzling artifacts）。
- **与他论文的关系线索（谱系关键节点）**：(1) 「只算该算的像素」=「只注入该注入的条件」——「query only the hole region」的按需计算思想与其 2026 年 training-free 按需注入（LightCtrl 只在 light mask 区域注入噪声）同构；(2) 隐式表示/坐标查询直接延续到其 VideoINR（视频隐式表示修复）线；(3) 「high-resolution efficiency」关怀与其 2021-2023 年 video super-resolution/inpainting 组（BasicVSR++ 合作、HD 视频修复）同频；(4) 一作 Weihuang Liu（澳门大学）后续与 Cun 合作的延续证明这是其导师式选题孵化模式的早期样本。

## 4 Idea 设计

- **Idea 原型：迁移驱动（主）+ 矛盾驱动（次）。** 迁移面： NeRF/SIREN 的「坐标→像素 MLP」从 3D 场景重建迁到 2D 修复，配 meta-learning 参数生成使其条件化于输入（「utilize a meta-learning strategy where the parameters of the pixel-wise query network are spatial-adaptive」，intro.tex）。矛盾面： 修复需要大感受野（整图进网络）vs 高分辨率算不起（「Learning the larger reception fields is time-consuming」）；以及「只需洞内像素 vs 解码器强制全图合成」（「the non-hole pixels are not necessary to be synthesized... To avoid such unnecessary computation」，method.tex Parameter Generation Network 节）——降采样编码 + 坐标查询一次性化解双矛盾。
- **问题表述句式**：设问式（本文独有）——「We raise a question: What makes the inpainting hard in efficiently handling the high-resolution images?」+ 枚举自答 (i)/(ii)。LightCtrl/CutClaw 用断言式，2021-2023 期用设问式，是其句式演化痕迹。
- **本文局限可能催生的后续**：(1) 自认复杂背景伪影（dazzling artifacts）→ 参数生成网络容量升级；(2) 坐标查询天然适配视频时序 → 隐式表示扩展到视频修复/超分（VideoINR 谱系）；(3) 「参数图 Φ 决定逐像素网络」的解耦 → 条件生成里「控制信号只进局部」的先声。
