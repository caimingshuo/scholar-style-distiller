# Idea 设计模式蒸馏指南 (Idea Design Distillation)

选题品味指南回答「这个学者选什么方向」；本指南回答更值钱的一层：**他怎么把方向做成一个 idea**——idea 从哪来、怎么收敛成一句话研究问题、凭什么通过他自己的筛选、以及一篇论文如何催生下一篇。蒸馏这一层，才能让「按他的风格帮我设计 idea」落地。

---

## 一、Idea 生成原型 (Idea Archetypes)

把语料中每篇论文的核心 idea 归入下列原型（一篇可有主次两个），统计该学者的**原型分布**——分布本身就是他的指纹：

1. **矛盾驱动 (Gap-Driven)**：发现既有范式的内在矛盾或错误假设。
   - *例*：ResNet——网络加深出现退化，而退化不该发生（恒等映射理论上可无损传导），矛盾直指优化而非容量。
2. **现象驱动 (Observation-Driven)**：实验中发现反直觉现象，由此提出假说。
   - *例*：Double Descent、Scaling Law 类工作——先把曲线画出来，再解释它。
3. **迁移驱动 (Transfer-Driven)**：把领域 A 的成功机制引入领域 B，真正的贡献是解决**适配矛盾**。
   - *例*：MAE——把 BERT 式掩码预训练迁到视觉，真正的洞见是「图像信息密度低，所以要 mask 75% 而非 15%」。
4. **简化驱动 (Simplification-Driven)**：对复杂系统做减法，剥离到只剩核心机制。
   - *例*：LoRA 之于适配层搜索；各种 "simple baseline" 之于堆模块的 SOTA。
5. **尺度驱动 (Scale-Driven)**：把已知方法推到极端尺度/极端条件，观察新行为。
   - *例*：把 batch size、模型尺寸、数据量扩大 100 倍看失效点。
6. **基准驱动 (Benchmark-Driven)**：造新任务、新数据集或新评测，定义新战场让别人来打。
   - *例*：ImageNet、GLUE 类工作。

记录格式：`原型 | 论文 | 该 idea 的一句话内核 | 证据（论文段落或 talk 引述）`。

## 二、问题表述句式 (Question Formulation Fingerprint)

顶尖学者的论文里几乎总有一句「一句话研究问题」，句式本身是稳定习惯。蒸馏时逐篇摘出该句（通常在 Introduction 第 2~3 段或 talk 开头），归纳其句式模板：

- 朴素设问式：*"Can we ...?"*, *"Is X really necessary for ...?"*
- 反假设式：*"What if the widely adopted X is not the cause, but ..."*
- 极致化式：*"How far can we push ... with only ...?"*

同时记录他**收敛问题的过程**：大方向（如自监督视觉）→ 关键子矛盾（对比学习依赖大 batch/字典）→ 一句话问题（能否用队列解耦字典大小与 batch size）。这条收敛链比最终问题更能教会你「怎么想」。

## 三、Idea 谱系图 (Idea Genealogy)

把语料论文按时间排开，画出演化链，对每条边标注生成逻辑：

```
MoCo v1 (2019) ──[局限：字典与 batch 耦合]──► MoCo v2/v3
     │
     └──[证明无监督表征可行，但训练扩展性存疑]──► MAE (2021) ──[...]──► 下一篇
```

要回答的三个问题：
1. 相邻论文是**延续**（上一篇的局限催生下一篇）还是**跳变**（换战场）？该学者的延续/跳变比例是多少？
2. 每条边的**触发信号**是什么：自己论文的局限、别人工作的启发、还是新硬件/新数据出现？
3. 若规律明显，据此推演「如果他今天继续做，下一篇会做什么」——这是给用户选题最直接的外推依据。

## 四、Idea 筛选的隐性标准 → Idea 记分卡

论文里看不到、但 talk/访谈/拒稿吐槽里常出现的，是他**砍掉 idea 的标准**。综合论文与补充语料，提炼 5~7 条 go/no-go 标准，做成记分卡，供实战时给用户的新 idea 打分：

| 维度 | 问题 | 打分锚点（1~5） |
| --- | --- | --- |
| 根本矛盾性 | 它触及底层矛盾还是边角问题？ | 5 = 直指被广泛默认的错误假设；1 = 在 SOTA 上加模块 |
| 一句话可陈述性 | 能否用一句朴素设问说清？ | 5 = 外行能听懂；1 = 需要三段背景铺垫 |
| 极简内核 | 去掉所有装饰后还剩一个纯粹机制吗？ | 5 = 核心变化可写进一行公式；1 = 有效性来自多组件叠加 |
| 可证伪性 | 能否设计出让审稿人无法反驳的关键实验？ | 5 = 单一变量扫描即定生死；1 = 只能靠堆 benchmark 分数 |
| 社区势能 | 别人会跟进吗？ | 5 = 开辟新任务/范式；1 = 只对单一数据集有意义 |

打分锚点中的措辞必须用该学者论文/访谈中的证据校准，不许凭空填写。

## 五、补充语料：论文之外

Idea 来源在论文里往往是隐形的，优先收集并引用：

- **Talk/Slides**：学者讲「为什么我们做这个」的场合，常出现论文里删掉的失败路径；
- **博客/访谈/播客**：选题价值观的直接陈述；
- **课程讲义与招生页**：其 lab 的研究纲领（research statement）；
- **被拒/撤稿与后续修改**：若公开，最能暴露其筛选标准的边界。

## 六、证据要求

- 每条原型归类、每条筛选标准，必须附 ≥2 篇论文（或 1 篇论文 + 1 处 talk/访谈）的具体佐证；
- 谱系图的每条边必须有触发信号的证据（如下一篇 Introduction 中对上一篇局限的引述），找不到证据的边标注「推断」；
- 打分锚点的每一条都要能回指到语料中的具体句子。
