# 学者风格特征档案模板 (Scholar Profile Template)

蒸馏完成后按本模板填写。**每条结论必须附证据（论文 + 位置 + 引用/图号），无证据的条目删除**。
产物存放：档案存 `./scholar_profiles/<scholar_name>/profile.md`，语料与中间产物存 `./scholar_profiles/<scholar_name>/corpus/`（不要写进 skill 安装目录，那里可能只读）。

---
